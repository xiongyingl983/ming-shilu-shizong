# 数据来源与可靠性（本技能全部内容的底稿说明）

## 1. 底本与译文来源

- **底本**：识典古籍《明实录》LS0026「世宗肃皇帝实录」全书 —— <https://www.shidianguji.com/book/LS0026>
- **卷数**：566 卷，另有卷首四篇（大明世宗肃皇帝实录序、进实录表、修纂凡例、修纂官）、
  全书目录（566 卷次与年月对照）、附录「异本二卷」（卷之二百二、卷之二百五之另本）。
- **原文**：该站所载繁体原文（明万历五年成书，监修张溶，总裁张居正等）。
- **白话译文**：该站「白话译文」（机器翻译，经人工检查），逐句附于原文之后。
- **对齐方式**：原文行与译文句子以 `logicSentenceId` 对齐。网页端译句顺序是乱的，
  本语料按**原文句序**还原，故可逐句回原文核对。

## 2. 语料构建方式（可复现）

1. **抓取**：逐章取页面内嵌 SSR 数据（`window._ROUTER_DATA` → `loaderData["__session/(lang$)/book/$"]`
   → `bookInfo.catalog.chapters` / `paragraphList`），4 线程，573 页全部成功、0 失败。
   采集脚本与踩坑记录见技能 `research/shidianguji-scrape`：
   - 站方 CDN 会出现字节 WAF JS 挑战（页面末尾 "Please wait..."，约 2.5 KB），需解 PoW：
     找 `i` 使 `sha256(prefix + i) == expect`，回填 `_wafchallengeid` cookie 后重发即可；
   - 请求**不得**带 `Accept-Encoding: gzip`（或 curl `--compressed`），否则只会拿到 JS 空壳。
2. **装配**：`research/ming-shilu-baihua` 技能的 `build_book.py`（raw JSON → 白话编年体 txt /
   GB18030 / 卷次索引 / PDF）。卷号与编次以**全书目录章**为准，并做双向自检。
3. **本技能内容生成**：book-to-skill 流程（`~/.agents/skills/book-to-skill`），
   把 566 卷切成 32 个约 12 万字的精读切片 → 32 份分片研读笔记 → 合成 21 个阶段章。

## 4. 已知缺失与风险（引用前必读）

- **译文是机器翻译**：含错译、漏译、半角标点、指代含混（例如把「上」译作「陛下」或「皇帝」不定）。
  凡引用须回原页核对；本技能 `scripts/raw_juan.py` 可逐句对照该站原文。
- **⚠ 已量化的系统性缺陷（三类，均经实测）**：
  1. **「上／帝」被译成先秦诸侯名**：译文在「上从之」「帝从之」这类句子上会译出
     齐景公／晋悼公／魏文侯／鲁庄公／齐孝公／卫庄公／哀公／悼公 等先秦诸侯 ——
     嘉靖朝叙事里出现这些名字**几乎必是机翻窜入**。**实测（随本技能交付的扫描器，词表去重后）：
     75 处、散布 68 卷**；未去重（短词与长词同时计数）时为 159 处、108 卷。
     读到时先回原页确认，再按原文（多为「上从之」）改读。
  2. **译文自造年号（非「后世内容窜入」，比原判断更精确）**：译文会给原文省略的年号**补上错误的年号**，
     实测「万历」28 处、散布 26 卷（多集中于卷之400 以后），并有个别**添加原文没有的事实**的情形。
     三条经原文比对的铁证（`scripts/raw_juan.py` 可复现）：
       · 卷之491（嘉靖三十九年十二月）原文作「改折江北等處馬匹，**四十年至四十一年**，每匹銀三十兩」
         → 译文作「**万历**四十年到万历四十一年…」（本卷即嘉靖朝，原文自指嘉靖四十年）
       · 卷之531（嘉靖四十三年闰二月）原文作「先是，**四十二年**，北虜入寇…」
         → 译文作「此前，**万历**四十二年，北方的敌寇入侵…」
       · 卷之566（嘉靖四十五年十二月）原文作「○癸巳追治**四十二年七月**」
         → 译文作「癸巳日，追究处理**万历**四十二年七月中**鸡鸣驿事件**中将领的罪责」
         —— 连「鸡鸣驿事件」都是原文所无，属**译文增补**（最危险的一类）。
     → **规则：凡译文出现非嘉靖年号（万历／神宗等），一律按该卷所属年号（嘉靖）回读原文**；
       引用前必须用 `scripts/raw_juan.py` 比对原文，切勿据译文立论。**原文层（繁体）经抽查无此问题**。
     ⚠ 另需区分：卷首《实录序》《进实录表》本为万历年间文书，那里的「万历」属正常，勿误判。
  3. **同一人名、同一地名的译形游移**（引用前必须回原页）：曾铣→杨铣／萧铣／仇铣／林铣；
     仇鸾→萧鸾／吕鸾／江鸾；翟鹏→梁鹏／盖鹏；陆炳→纪炳；石天爵→史天爵／李天爵；
     牛天麟→半天麟；翁万达→王万达；董旸→董晹；徐樾→朱樾／徐槌／崔维；石宝→石瑶；许泰→朱泰；
     赵炳然→杨炳然；胡镇→湖镇；杨选→张选；洪迪珍→林迪珍；胡松→李松；马墀／孙松／陆松；
     朱衡→王衡；黑春→王春；张臬→张杲；黄光升→王光升／邹光升；周珫→周㧤；张经→杨经／马经纶；
     李默→沈黙；曹邦辅→胡邦辅；杨顺→甘顺／李顺；吴雕→（异写）；薛甲→陈甲／王甲／沈甲；
     桂萼奏事件误系张璁；《山西提学副使》混作陆梁／桂深／苏深；「纪炳」即陆炳。
     实测与工具：`python scripts/scan_mt_defects.py`（--cls A/B/C、--kw 单查）。
  **已核否的两条「疑似规律」**（勿当规则沿用）：①「苏州＝蓟州」误译**不成立**——
  苏州 227 处、蓟州 332 处，多为正常地名，只是个别段落可疑；②景王之国在语料中不写作
  「之藩／就国」（「之藩」0 处、「之国」3 处且均非景王），系白话译文的用词差异，非漏收。
  ③「景帝」「康王」「司马睿」等**不构成**缺陷类：卷之8、卷之14 的「景帝」讲的是明代宗景泰帝
  （郕戾王），属正常史事；「康王」多为藩王谥号或古典引用；「司马睿」全书仅 1 处（卷之212），
  属个别可疑，未形成规律。**只有第 1 类（先秦诸侯名）是已证实的批量缺陷**。
- **⚠ 检索方法（对白话译文语料至关重要）**：必须用**白话词**检索，用文言词会严重漏检 ——
  实测：留中 2 处、之国 3 处、之藩 0 处、特旨 6 处、勘报 2 处，而白话形式的「不报」有 45 处。
  想找「留中」请搜「不批复／留在宫中／搁置」，想找「之国」请搜「前往封国／到封国」。
- **原文截断**：原站部分段落以省略号结尾（卷之311、313、315、322、324 等），非本语料丢失，
  引用到这类段落须回原页补全。
- **干支与月份错位**：部分卷（如卷之45末、47、54、112）译文干支与所系月份不合，或首条日期
  因跨页断行而缺失；卷之80–83 原站明标「馆阁所藏本有缺失」。
- **43 处无译文**：原站在这些句子上无「白话」条目，语料以 `【】` 补入简体原文，未作翻译。
- **异本二卷**：卷之二百二、卷之二百五各有第二种版本（卷首题「本卷據〔廣〕本」），
  原件卷号、年月与本编重出，已移入语料附录，不计入 566 卷。
- **原站题名有误者**：少数章的题名卷号与目录不符（如题「二百七十八」而内容年月属卷之二百八十），
  本语料一律依目录与内容年月编次。
- **卷次对应的年月**：卷题括注的年月取该卷首条日期，个别卷（如卷之五十六、二百八十、五百三十四）
  原站首条日期跨页断开，已据目录补足。
- **本技能只含 世宗朝 实录**：不含太祖至武宗各朝、也不含《世宗宝训》25 卷；
  文中「修纂凡例」提到的宝训条目不在语料内。
