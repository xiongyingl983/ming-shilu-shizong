# 第13章　显陵告成、玄修日盛与宫变前夜

覆盖范围：卷之226—卷之262（嘉靖十八年七月—嘉靖二十一年闰五月）

## 核心要义（1–3句）

本阶段世宗朝双轨并进：一是显陵二圣祔葬祔庙与太庙大工连年不停，牵动湖广、四川采木与南直隶、河南赋役；二是世宗以病罢朝、宠方士陶典真（陶仲文）而行玄修，礼制与斋醮同治。边事重心西移至延绥、固原、宁夏一线，安南之役以莫登庸献籍纳降收束；北虏石天爵两度求贡终遭诱杀，为此后大举入犯埋下引信（卷226—卷262）。

## 框架与判断规则（3–6条）

1. 当宗藩或内臣援例请乞时，应以户部执奏为常态、帝特允为破例，因为德王请复三湖地、徽王乞长芦盐引皆部执不可而帝特给之（卷226·十八年七月、卷231·十九年十一月）。
2. 当遇灾异时，应预期「修省—罢工—蠲赋—自陈」闭环，因为黄雾风霾后命兵部议边务、久旱则帝亲祷西宫、禁屠宰、百官青衣斋戒（卷235·十九年三月、卷247·二十年三月）。
3. 当北虏遣使求贡时，应警惕边臣杀降邀功之弊，因为石天爵两度求贡终被巡抚龙大有诱杀誑功（卷251·二十年七月、卷262·二十一年闰五月）。
4. 当读边事战果时，应合读勘报与同卷处分条，因为江桓以斩二级冒功即被诏停俸戴罪，而宣府连捷、黑水苑大捷另有勘叙（卷228·十八年八月、卷241·十九年九月、卷243·十九年十一月）。
5. 当言官所劾对象为权贵时，其效力不定，因为劾救火迟至者反以犯大不敬谪戍，而劾郭勋、胡守中者或被害或得用（卷231·十九年十一月、卷248·二十年四月、卷253·二十年九月）。
6. 当涉及礼制争议时，应留意大礼议余绪仍在塑造士论，因为睿宗配享大享、议薛瑄与王守仁从祀孔庙皆不许（卷228·十八年八月、卷229·十八年九月、卷235·十九年三月）。

## 关键概念（6–10条）

- **显陵二圣祔葬祔庙**：二圣玄宫成、章圣皇太后南祔，历合葬新寝、祔太庙、睿宗配享（卷226·十八年七月—卷229·十九年九月）。
- **玄修与真人封号**：封陶典真为神霄保国弘烈宣教振法通真忠孝秉一真人，领道教事，后加少保、礼部尚书（卷229·十九年九月、卷243·十九年十一月）。
- **勘报**：战功罪责由纪功给事中、巡按御史勘上，读实录须与勘疏互证（卷271、卷279）。
- **通贡—拒贡—杀使循环**：俺答求贡被绝、悬赏购其首，使者被杀（卷251·二十年七月、卷262·二十一年闰五月）。
- **庙灾修省**：太庙灾后颁哀诏、蠲逋赋、停不急工役、令两京大臣自陈（卷248·二十年四月）。
- **京察与大计**：京察罢黜五品以下六十余人，大计黜老疾贪酷等二千五百三十四员（卷228·十八年八月、卷245·二十年正月）。
- **钱法与折色**：补铸嘉靖通宝、好钱七十文折银一钱；王府禄米定折银永例（卷230·十九年十月、卷226·十八年七月）。
- **岁例银与挪借**：太仓、太仆寺银屡被挪借以支工程与边饷（卷230—卷262）。
- **白爵宣府五弊**：将不知兵、士无斗志、烽堠不警、权轻令不行、管粮官牵制（卷239·十九年七月）。
- **安南都统使司**：铸印赐莫登庸，安南之役以纳降收束（卷248·二十年四月）。

## 心智模型（2–4条）

1. **双轨并进**：礼制大工与斋醮玄修同时推进，工役与财政压力同源；显陵、采木与雷坛、仙银诸事并行（卷226—卷262）。
2. **帝意亲裁压倒部议**：部臣执奏多为形式，破例之权终归亲批；梁材以争郭勋包工去位即其显例（卷236·十九年四月）。
3. **边患重心西移**：宣大之外，延绥、固原、宁夏成为吉囊、俺答主攻方向，明方虽有两捷而冒功逗遛之弊未除（卷241、卷243、卷244）。
4. **直言之价随对象而变**：阿附者得宠、直言者贾祸，构成宫变前夜的朝局底色（卷246·二十年二月杨爵下镇抚司）。

## 反模式（2–4条）

1. 以部议结果预判结局——户部执不可之后仍常有「帝特允之」，须读到亲裁一层。
2. 把边衅一律读作虏方起意——石天爵被诱杀、董宝杀使冒功，衅端多起于明方边臣（卷262、卷311）。
3. 单读战功条而不读同卷处分条，易误判边将进退。
4. 把译文夹注（添注、释义）当作实录原文引用，须回原文校核。

## 工作例证（1个完整实例：缘起—过程—结果—出处）

**显陵祔庙大工：从二圣南祔到兴都礼制成书**

- **缘起**：嘉靖十八年七月，显陵二圣玄宫成，章圣皇太后灵柩南祔，命刘天和、潘鉴、欧阳铎等提督显陵工（卷226·十八年七月）。
- **过程**：闰七月合葬新寝（卷227·十八年闰七月）；八月慈孝献皇后祔太庙（卷228·十八年八月）；九月睿宗配享大享（卷229·十八年九月）。工役牵动湖广、河南赋役，二十年二月显陵内城及旧邸宫殿完工，礼部议作《承天大志》以督工尚书顾璘总裁，图列统德山形胜与显陵规制（卷246·二十年二月）。二十年四月太庙火灾，惟睿庙独存，帝素服西角门颁哀诏修省、停工役、蠲逋赋，五月议修宗庙，命潘鉴往湖广、戴金往四川专督采木（卷248·二十年四月、卷249·二十年五月）。
- **结果**：二十一年三月顾璘督显陵工竣、献《兴都志》，陈兴都礼制四事，定显陵不设岁暮祭（卷258、卷259·二十一年三月）；陵碑御书（卷261·二十一年五月）；潘鉴以采木功升右都御史（卷262·二十一年闰五月）。
- **出处**：卷226（十八年七月）、卷227（闰七月）、卷228（八月）、卷229（九月）、卷246（二十年二月）、卷248—卷249（二十年四至五月）、卷258—卷259、卷261—卷262（二十一年三至闰五月）。

## 关键要点（3–7条）

- 本阶段主线为显陵大工与玄修政治交织，陵工持续近两年，牵动湖广、河南、南直隶赋役与赈济。
- 大礼议余波未息：睿宗配享、从祀之争、议礼功臣之进退荣哀，共同塑造礼制与士论。
- 朝局党争与言路收紧并行：郭勋、夏言、霍韬、严嵩数方互攻，杨爵等直言获罪。
- 财政与工役结构紧张：太仓、太仆寺银屡被挪借，京察黜官数千。
- 石天爵两度求贡终遭诱杀，为二十一年六月北虏大入山西埋下引信。
- 本卷群实为宫变前夜之朝局，壬寅宫变（二十一年十月）不在本切片。

## 与其他章的关系（2–4条）

1. 上承第十二章（卷212—卷225）的显陵营建与礼制改制，本章以二圣祔葬、祔庙、配享收束其工程线。
2. 下启第十四章：太庙火灾后的庙制重建在卷279—卷281定案「同堂异室、睿宗祔太庙」；石天爵被诱杀之衅在二十一年六月化为北虏大入山西（卷263—卷264）。
3. 与第十五章遥相呼应：本章「拒贡—杀使」之循环，至二十五年、二十六年演为堡儿塞被杀、番文求贡而终未许（卷311、卷313、卷314）。
4. 边事勘报之法（纪功给事中、巡按勘上）为第十四、十五章读战功条的通用工具。
