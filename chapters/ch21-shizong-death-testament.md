# 第21章　世宗之崩与遗诏新政

覆盖范围：卷之558—卷之566（嘉靖四十五年五月—嘉靖四十五年十二月）

## 核心要义（1–3句）
这是世宗朝最后八个月：一面是玄修搜求金玉珍珠、边事屡失与盗乱并起，一面是十二月庚子世宗崩、裕王自东安门入宫成服，辛丑小殓颁遗诏（卷566·四十五年十二月）。遗诏既是徐阶拟定之新政纲领，也是裕王继统合法性的文书基础：自陈过求长生、惑于奸人，命停罢斋醮采买，存者召用、殁者恤录、见监者释放。

## 框架与判断规则（3–6条「当…时，应…，因为…」，带卷号）
1. 当遗诏既定时，应行「以日易月、二十七日释服」之丧礼，因为世宗遗诏明定毋禁民间音乐嫁娶（卷566·四十五年十二月）。
2. 当新君未即位而国疑时，应请裕王主丧、自东安门入宫成服，因为徐阶等即依此定策而国本遂安（卷566·十二月）。
3. 当建言诸臣获罪时，应于遗诏中存者召用、殁者恤录、见监者先释放复职，因为遗诏以此为收拾人心之首务（卷566·十二月）。
4. 当边事失事时，应循巡按勘报—总兵降级或闲住、督抚革职候勘之模式，因为定边营之败即依此处置（卷563·十月、卷564·闰十月）。
5. 当宗藩冒封越例时，应查核追夺，因为襄垣王充煌冒封被查（卷558·五月、卷566·十二月），肃府朱缙𤏳不补袭王爵（卷563·十月）。
6. 当科道与内阁交争时，应警惕朋党之祸，因为胡应嘉等劾大学士高拱、高拱疏辩牵涉徐阶与冯保（卷565·十一月），按语已称「几乎酿成朋党之祸」。

## 关键概念（6–10条）
- 遗诏：辛丑小殓颁，壬寅大殓、上谥号庙号、葬永陵（卷566·十二月）。
- 遗诏新政纲领：停罢斋醮采买、方士付法司论罪、建言诸臣召用恤录释放（卷566·十二月）。
- 裕王主丧：徐阶等请裕王主丧，裕王自东安门入宫成服（卷566·十二月）。
- 高拱被劾：胡应嘉等劾其二不忠，高拱疏辩（卷565·十一月）。
- 龙州薛兆乾叛逆：处死抄家，母及同党二十二人论斩（卷558·五月）。
- 三巢之剿：吴百朋请剿广东岑冈、江西龙南三巢，俞大猷破李亚亢擒斩一万余（卷561·八月）。
- 开天津海运：由滦河转输永平军饷（卷560·七月）。
- 督理水利之议：凌云翼请设督理水利御史，工部议以巡盐御史兼管（卷558·五月）。
- 久任之法：郡县官未满三年不得推升，督抚任满加级留任（卷558·五月）。

## 心智模型（2–4条）
1. 「玄修—疾病—遗诏悔过」因果链模型：卷563·十月已载世宗病状，卷566·十二月遗诏自陈过求长生并停罢斋醮采买，前后相承。
2. 「内库搜求与边饷告匮并存」模型：催金珠（卷558·五月）与取没官银二十万入库（卷559·六月）并行，而各地仍请捐纳、截留。
3. 「遗诏即新政纲领」模型：遗诏所定用人、停罢、恤录诸条，实为隆庆初政的日程表（卷566·十二月）。
4. 「科道—内阁对立」模型：胡应嘉劾高拱、高拱辩疏牵涉徐阶冯保，为隆庆初徐阶—高拱之争的前奏（卷565·十一月）。

## 反模式（2–4条）
1. 以进献祥瑞邀宠：臣民争进法秘、仙桃、瑞芝者甚众，于国事无补（卷558—卷566间屡见）。
2. 以内库所需催逼矿金珠玉：催云南矿金三千两、库银十万两，并催广东、云南珍珠宝石（卷558·五月）。
3. 以问责掩饰制度之弊：边事失事即降级革职，而边饷、募兵诸弊不改（卷563·十月、卷564·闰十月）。
4. 以廷杖钳制言路：何以尚请宽海瑞，廷杖下镇抚司狱（卷563·十月）。

## 工作例证（1个完整实例：缘起—过程—结果—出处（卷号＋年月））
**世宗崩与遗诏**
缘起：四十五年，世宗久病居西苑（卷563·十月已载其病状），国本久虚，玄修求药之念未息，尝欲南巡承天取药，赖徐阶力谏乃止（卷554·四十五年正月）。
过程：十二月庚子世宗崩，徐阶等请裕王主丧，裕王自东安门入宫成服；辛丑小殓颁遗诏（卷566·十二月）。
遗诏要旨：自陈以宗室入继、在位四十五年，因多病过求长生、惑于奸人，祷祠土木并举，「既违先皇之训，亦负初心」；命裕王「上遵祖训、下顺舆情，嗣登大位」；丧礼以日易月、二十七日释服，毋禁民间音乐嫁娶；亲王郡王不得擅离封地，督抚三司不得擅离职守；建言得罪诸臣存者召用、殁者恤录、见监者即先释放复职；方士付法司论罪；斋醮采买「一切劳民伤财之事悉皆停罢」；祔葬祔享各稽祖宗旧典斟酌改正（卷566·十二月）。
结果：壬寅大殓、上谥号庙号、葬永陵（卷566·十二月）。
出处：卷563·四十五年十月、卷554·四十五年正月、卷566·四十五年十二月。

## 关键要点（3–7条）
1. 遗诏自陈过求长生、惑于奸人，命停罢斋醮采买（卷566·十二月）。
2. 遗诏为裕王继统合法性的文书基础（卷566·十二月）。
3. 财政内库搜求与边饷告匮并存（卷558、卷559、卷563）。
4. 边事问责循勘报—降革—优恤之固定模式（卷563、卷564）。
5. 科道与内阁、吏部对立，为隆庆初徐阶—高拱之争前奏（卷565）。
6. 宗藩条例趋严，冒封必查（卷558、卷563、卷566）。

## 与其他章的关系（2–4条）
1. 上承第20章：世宗末年玄修营建与财政亏空之势延续至本章（卷558—卷565）。
2. 下启隆庆朝：遗诏所定召用恤录、停罢斋醮诸条，为隆庆初政纲领（卷566）。
3. 回照第19章：遗诏所斥「惑于奸人」之政，正与第19章严嵩柄国、卷552严嵩被追论相终始。
