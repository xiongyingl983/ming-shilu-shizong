# 第7章　郊祀分祀与亲蚕定礼

覆盖范围：卷之100—卷之113（嘉靖八年四月—嘉靖九年五月）

## 核心要义（1–3句）

本段十四卷是世宗以「复古制」为名推进礼制改造的关键一段：天地分祀、皇后亲蚕、社稷改配三大议题先后定案，帝意压过群臣票数（卷之109、111、112）。与此同时，议礼新贵张璁、桂萼在同一年内完成「被劾去位—旋又召还」的循环，显示其去留取决于帝对议礼功绩的记念，而非言路弹劾的力度（卷之104、105、107）。宗禄、庄田、荒政与边饷始终吃紧，财政症结与礼制争论共处同一条时间线（卷之100、102、112）。

## 框架与判断规则（3–6条）

1. 当郊祀大礼被归为「古制」之争时，应把礼部票数与帝意分开看：九年三月礼部汇群臣郊议，合祭二百六人、分祭八十二人，帝仍决南北分祀，因为最终裁定权在皇帝（卷之111）。
2. 当议礼新贵遭言官猛攻时，应预判其未必立即失势：张璁八年八月被劾令归、九月即召还，桂萼八月致仕、十一月召还，因为帝念其议礼之功（卷之104、105、107）。
3. 当配享规格进入议程时，应预期阁臣内部再度分裂：郊祀配典上张璁力主二祖同配、夏言主太祖独配，往复争辩，因为配位牵涉太祖与太宗的正统位次（卷之112）。
4. 当边患与土鲁番、哈密交涉同时出现时，应优先取守势判断：王琼主守不主战并列「五不足」，因为当时兵饷两绌（卷之100）。
5. 当宗禄与武职俸禄开支膨胀时，应以裁冗、收官、折银三法应对：宗禄严妻妾之限、庄田收官、荆襄辽寿等府禄米折银，因为宗室繁衍而田额反减（卷之100、102、107）。

## 关键概念（6–10条）

- 郊祀分祀：冬至祀天于圜丘、夏至祭地于方泽，孟春于大祀殿祈谷；帝斥合祭之制始于王莽（卷之109、111）。
- 亲蚕礼：皇后于北郊先蚕坛行亲蚕，九年三月丁巳皇后行礼（卷之109、111）。
- 《郊祀考议》：张璁辨《周礼》圜丘方泽之制、斥王莽合祭之非的奏议（卷之111）。
- 社稷改配：九年正月去太祖、太宗之配，复勾龙氏、后稷氏（卷之109）。
- 五不足：王琼论土鲁番时所列五项难处，为其守势论据（卷之100）。
- 诏告天下：八年八月戊寅之诏，述议礼本末与璁萼功罪、党附处置（卷之104）。
- 举主连坐：吏部慎选久任五事之一，推荐失当者连带举主（卷之101）。
- 巡按御史约束十二条：汪鋐所上宣谕、遍巡、举劾限名、禁逢迎之规（卷之109）。
- 裁冗收官折银：应对宗禄与冗官的三项财政手段（卷之100、102、107）。

## 心智模型（2–4条）

1. 「帝意—礼部票数—阁臣配位」三层结构：礼部汇议提供正当性、票数显示群臣倾向，真正的分岔点在皇帝对配位与正统的裁定（卷之111、112）。
2. 「去位—召还」循环：议礼集团成员往往一落一起，关键变量是帝对议礼功绩的记念，而非言官弹劾的力度（卷之104、105、107）。
3. 财政与礼制同轨：礼制工程与赈灾、边饷共用同一资源池，九年四月真定人相食与五月郊坛兴工同时出现（卷之112、113）。
4. 司法双轨：东厂与刑部在张福案中相争，守法司者反遭严谴，可见当时刑狱之权的轻重（卷之103）。

## 反模式（2–4条）

1. 把礼制之争只看作经学辩论：郊祀分祀、亲蚕皆始倡于夏言而决于帝意，忽略皇权意志会误判走向（卷之109、111）。
2. 以弹劾数量推断大臣去留：陆粲劾璁萼后二人短期去位，但数月内即召还，言路并非决定变量（卷之104、105、107）。
3. 将边饷与荒政分开处理：庄田收官、宗禄折银与边镇发帑同为一条财政链，分头处置会低估缺口（卷之100、112）。
4. 轻信译文人名：本段白话译文中窜入他朝人名与异写，引用须回溯史源（卷之105、111、112）。

## 工作例证（1个完整实例）

郊祀分祀之定案。

- 缘起：嘉靖九年正月，帝谕礼部，谓南郊祭天、北郊祭地为古制，斥合祭始于王莽，命议之（卷之109，嘉靖九年正月）。
- 过程：九年三月礼部汇群臣郊议，合祭二百六人、分祭八十二人，折衷诸说并列；张璁进《郊祀考议》，辨《周礼》圜丘方泽之制（卷之111，嘉靖九年三月）。
- 结果：帝决南北郊分祀，冬至圜丘、夏至方泽、孟春大祀殿祈谷；四月定配典，太祖独配圜丘方泽、二祖同配大祀殿；五月郊坛兴工，敕郭勋、张璁等董其事（卷之111、112、113，嘉靖九年三月至五月）。
- 出处：卷之109（嘉靖九年正月）、卷之111（嘉靖九年三月）、卷之112（嘉靖九年四月）、卷之113（嘉靖九年五月）。

## 关键要点（3–7条）

1. 分祀定案是「帝意压票数」的典型：八十二票对二百六票，仍定分祀（卷之111）。
2. 亲蚕与分祀同出于夏言之倡，而世宗以「疑谋勿成」拒异议（卷之109）。
3. 张璁、桂萼在本段完成一次去位—召还循环（卷之104、105、107）。
4. 宗禄与冗官是财政症结：洪武田土八百四十九万余顷至弘治仅存四百二十二万余顷，山西藩禄自万石增至八十七万石（卷之102）。
5. 荒政与边饷并行：延绥大饥发帑银十五万（卷之112），五月蠲赈遍及山西、陕西、南直隶（卷之113）。
6. 庙制讨论有边界：何渊妄议太庙世室，谪永州卫经历（卷之106）。
7. 卷之112「八月初六日」下之敕谕与同卷四月纪事不合，其系年存两说，须核对原卷（卷之112）。

## 与其他章的关系（2–4条）

1. 上承第6章（嘉靖七年三月—嘉靖八年三月）：《明伦大典》前后的议礼定案余波未尽，本章转入郊祀、亲蚕等祭祀层面的改制（卷之100—113）。
2. 下启第8章（嘉靖九年六月—嘉靖十年闰六月）：四郊坛定名、孔子祀典订正、祧庙大禘相继展开（卷之114—127）。
3. 与第9章（嘉靖十年七月—嘉靖十三年正月）的宗庙改制构成连续议题：分庙之议凡三提，皆可溯至本段社稷改配与庙制之议（卷之109、130、132、136）。
4. 边事与财政线索接入第8、9章：土鲁番、套虏与太仓银拨补之机制在此段成形（卷之100、102、106）。
