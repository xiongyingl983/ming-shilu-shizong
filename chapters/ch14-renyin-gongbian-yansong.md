# 第14章　壬寅宫变与严嵩代夏：庙制定案与九边告急

覆盖范围：卷之263—卷之303（嘉靖二十一年六月—嘉靖二十四年九月）

## 核心要义（1–3句）

本阶段以壬寅宫变（二十一年十月）为枢纽：宫变后帝以手诏、亲批直接处置辅臣与科道，夏言革职而严嵩入阁代夏；太庙灾后重建之议终归「同堂异室」旧制、睿宗祔入太庙。同期北虏大入山西、破卫所州县、京师戒严，边臣层层获罪；财政已呈以银养兵之局（卷263—卷303）。

## 框架与判断规则（3–6条）

1. 当阁臣或科道被处置时，应读手诏与亲批而非廷议结果，因为世宗手诏谕都察院斥夏言「放纵肆意已成习性」、责言官，并亲批指严嵩嘱托私书为伪（卷263·二十一年六月、卷275·二十二年六月）。
2. 当发生宫变或灾异时，应预期「灾异—修身—谢神」的话语重构，因为十月以逆谋未遂记事，十一月即以敕谕述宫变、告谢天地宗庙社稷以安人心（卷267·二十一年十月、卷268·十一月）。
3. 当议庙制时，应预期帝以「复祖宗旧制」否定群臣昭穆之议，因为群臣上睿宗祔孝宗庙、昭穆同世之议，帝终谕复「前庙后寝后祧」同堂异室（卷279·二十二年十月、卷280·十一月）。
4. 当判断边事胜负与将吏罪状时，应以勘报为证据链，因为山西失事由张尧年等勘上、宁条梁捷亦由勘叙（卷271·二十二年二月、卷279·十月）。
5. 当严嵩屡被劾而帝慰留时，应视为帝意庇护而非言路失效，因为叶经、伊敏生、许赞诸劾皆得温旨（卷252·二十年八月、卷256·二十一年十二月、卷275·二十二年六月）。
6. 当出现通贡之议时，应警惕杀降冒功之弊，因为石天爵事在前、二十一年六月北虏随即大入（卷262·二十一年闰五月、卷263·六月）。

## 关键概念（6–10条）

- **壬寅宫变**：宫婢杨金英等绳勒帝误结不死，张金莲告皇后得救，宁嫔王氏、端妃曹氏皆凌迟族诛（卷267·二十一年十月）。
- **手诏亲批政治**：帝以手诏、亲批直裁辅臣与言路，内阁与外廷议决常被推翻（卷263、卷264、卷275、卷280）。
- **同堂异室庙制**：前太庙、后寝殿、再后祧庙，睿宗祔入太庙（卷279—卷281）。
- **勘报**：纪功给事中、巡按御史勘上战果与罪状，读实录须与勘疏互证（卷271、卷279）。
- **太仓银北输**：屡发太仓银、太仆寺马价银至宣大、三关、延绥、宁夏、辽东，动辄数万至数十万两（卷263—卷281）。
- **大享殿与玄极宝殿**：大享礼、祈谷等大典多在玄极宝殿举行（卷266·二十一年九月）。
- **起复与致仕**：夏言革职—复官—再罢—再起，构成此期辅臣进退的常态节奏（卷264、卷281）。
- **考察揭帖定例**：令抚按以政绩揭帖封送吏部，永为定例（卷270·二十二年正月）。
- **宗室高墙**：定宗室入京即发高墙之律（卷278·二十二年九月）。
- **盐法与边饷**：定九边盐引预派开中、屯田永免赋之法（卷278·二十二年九月）。

## 心智模型（2–4条）

1. **皇权直接化**：帝以手诏与亲批越过阁部处置大员，内阁与廷议的议决效力取决于是否与帝意合（卷263、卷264、卷275、卷280）。
2. **宫变的话语包装**：先以逆谋未遂记事，再以灾异—修身—谢神重构，随之收紧宫廷宗教——逐番僧、禁尼姑、避定磉之讳（卷276·二十二年七月）。
3. **廷臣相争被定为边患根因**：周怡谓辅臣、边臣相争则无以安内攘外，直指翟銮—严嵩—许赞与张凤—周尚文—翟鹏两组不和（卷275·二十二年六月）。
4. **大礼议收尾在庙制**：以恢复旧制为名否定七庙昭穆之议，形式复古而实质尊崇本生（卷280·二十二年十一月）。

## 反模式（2–4条）

1. 以为阁权或廷议可制约帝意——手诏、亲批与「帝疑」往往是真正的转折点。
2. 把「复祖宗旧制」直接读作复古保守，忽略其尊崇本生的实质。
3. 只读战果条与捷报，不读同期的勘疏与处分条，易高估边将位置。
4. 把译文窜入的后世年号、晚明人名（如卷267奏疏中的贺人龙、猛如虎）当作史实。

## 工作例证（1个完整实例：缘起—过程—结果—出处）

**壬寅宫变与移居西苑**

- **缘起**：二十一年六月，虏十余万骑自双山墩入，破沙沟墩，越雁门南下代州、太原；世宗手诏谕都察院斥夏言、责言官，调三关兵分守紫荆、居庸、白羊、倒马诸关，起翟鹏总督（卷263·二十一年六月）。
- **过程**：二十一年十月二十一（敕所记），宫婢杨金英等以绳勒帝误结不死，张金莲告皇后得救；宁嫔王氏主谋、端妃曹氏预谋，皆凌迟族诛（卷267·二十一年十月）。
- **结果**：十一月帝敕谕中外述宫变，告谢天地宗庙社稷以安人心；许绅以进药护驾功升礼部尚书、加太子太保（卷268·二十一年十一月）。宫变之后宫廷宗教随之收紧：申禁尼姑令还俗、建州之变并起（卷276·二十二年七月、卷268·十一月）。
- **出处**：卷263（二十一年六月）、卷267（二十一年十月）、卷268（二十一年十一月）、卷276（二十二年七月）。
- **两说/待核**：宫变后是否移居西苑，本切片无明文，仅见禁苑、西苑瑞谷与督农（卷277·八月、卷279·十月）及禁苑北墙下大慈恩寺（卷272·三月）；须回原文与前卷核（两说：移居西苑见于后世记述，本卷群未明载）。

## 关键要点（3–7条）

- 壬寅宫变是本阶段枢纽，其记事方式（逆谋未遂→灾异谢神）决定此后宫廷宗教与朝局的走向。
- 夏言与严嵩消长已成定局：夏言七月革职闲住、十二月复原官致仕，严嵩八月入阁仍掌礼部。
- 庙制之争在卷279—卷281定案，睿宗祔太庙，世宗以旧制之名收束大礼议。
- 北虏大入山西，破卫所十余、州县三十八，杀掠男女十余万，勘疏称诸将「绝对没有敢向敌军营地射出一箭的人」（卷263—卷264、卷271）。
- 边臣以层层勘罪被惩：翟鹏起复又解职，李蓁、张达、王升、白爵论死（卷271·二十二年二月、卷280·十一月）。
- 财政已呈以银养兵之局，岁例银、盐引、马价银、南京借粮为边饷主渠道。

## 与其他章的关系（2–4条）

1. 上承第十三章：太庙火灾（卷248·二十年四月）后的庙制重建在本章定案；石天爵被诱杀之衅在二十一年六月化为北虏大入山西（卷263—卷264）。
2. 下启第十五章：严嵩二十三年九月兼吏部尚书、谨身殿大学士（卷290），二十四年七月加太子太师、八月加少师（卷301、卷302），复套议与夏言之死在彼章收束。
3. 本章「以备为实、以贡为权」的边臣共识，在第十五章演为俺答屡遣使叩边而终未获许（卷311、卷313、卷314）。
4. 本章确立的庙制终局，为第十五章大享殿、皇乾殿与玄极宝殿配享之礼提供制度前提（卷302）。
