# 第8章　郊庙改制与孔子祀典

覆盖范围：卷之114—卷之127（嘉靖九年六月—嘉靖十年闰六月）

## 核心要义（1–3句）

这十四卷（约十三个月）把郊祀改制推向收尾——《大明集礼》刊行、四郊坛定名、冬至圜丘大赦——同时将改制锋芒转向孔子祀典与宗庙祫禘，去王号、易木主、迁德祖入祧庙、定大禘虚位（卷之114、116、117、119、121、122、124）。帝权与言路的张力在赵时春、高金、赵汉诸案中反复出现，而张璁虽屡遭攻讦却始终获慰留，十年二月且赐名孚敬（卷之115、117、122）。

## 框架与判断规则（3–6条）

1. 当皇帝欲改易孔庙、郊庙等大祀典制时，应预判言官必以「尊崇圣师、恪守圣祖成法」相争，因为此类议题被赋予「正统」象征，议者常以「天下公议」对抗君权（卷之117、119、123）。
2. 当张璁、桂萼、方献夫等议礼新贵柄政时，应预期吏部用人必被指为「援引同乡、私改天官之选」，因为大礼议遗留的党派怨恨未消（卷之115）。
3. 当边报警急而各镇推诿时，应即令三关、大同、延绥互相救援并重罚违令者，因为三镇地相连而守臣各以邻为壑（卷之116、123、127）。
4. 当灾异频见（火灾、雷震、彗孛）时，应预料礼部必上「修省」之奏并牵连人事，因为嘉靖初灾异被用作修省与举劾的双重工具（卷之126、127）。
5. 当言官以灾异讥切朝政时，应预判其多遭拷讯或贬调：赵时春因灾异上言下锦衣卫拷讯、高金言邵元节不宜下锦衣卫逮问，因为帝视之为借灾异胁制朝廷（卷之115、117）。

## 关键概念（6–10条）

- 《大明集礼》：九年八月刊行，帝亲序并校补颁行（卷之114、116）。
- 《祀仪成典》：十年十月命张璁、李时编郊祀规制之书（卷之118）。
- 孔子祀典：改称「至圣先师」，去王号与文宣大成之号，庙不称殿，易塑像为木主，笾豆十、乐舞六佾，别祠启圣公（卷之117、119）。
- 大禘：十年正月定以皇初祖虚位、太祖配享，夏秋冬祫祭同孟春（卷之121、122）。
- 祧庙：十年正月迁德祖入祧庙、太祖主居寝殿正中（卷之121）。
- 四郊坛名：南郊东坛曰天坛、北坛曰地坛、东郊曰朝日坛、西郊曰夕月坛（卷之114、119、122）。
- 墩台堡寨法：五里一墩、十里一堡，配佛郎机铳（卷之117）。
- 三途并用：科举、岁贡、荐举并行之诏（卷之121）。
- 并赃计赃：许赞所陈律意之辨，并移会典（卷之114、115）。
- 暑月缓枷、霜降详审：恤刑定期之例（卷之115、118）。

## 心智模型（2–4条）

1. 「正统象征—公议话术—君权裁定」三段式：孔子去王号、撤姚广孝太庙配享皆先由帝谕发端，再交礼部会议，最终以帝断收束（卷之116、117、119）。
2. 「帝倚重个人」与「制度性怨恨」并行：张璁屡遭攻讦而屡获慰留，十年二月赐名孚敬，说明帝对议礼功臣的个人倚重不受言路左右（卷之122）。
3. 灾异即政治语言：十年正月至闰六月宫中火、部院火、雷震午门、彗星出东井接连出现，每次均伴修省与人事（卷之121、124、126、127）。
4. 边镇互援是唯一可行解：三镇守臣互相救援之令的出台，正因单镇独守无法应付连片边警（卷之116、123、127）。

## 反模式（2–4条）

1. 以人事更替推断路线转向：桂萼致仕、方献夫致仕并不等于礼制改制停止，孔子祀典与祫禘改制仍在推进（卷之117、121）。
2. 把灾异奏疏当纯技术讨论：许赞四事、赵时春四事三急、顾鼎臣钱粮四事皆以灾异为引，实际指向律意、人才与田粮旧额（卷之114、115、118）。
3. 依赖译名判断人物：卷之114刑部尚书作「许瓒」、卷之118以下并作「许赞」，卷之116「薛甲」又作「陈甲」「王甲」，其人名存两说，须回原文校正（卷之114、116、118）。
4. 低估边患的连续性：海贼、川盗、山西山贼与套虏同时并起，只盯一路会漏判局势（卷之116、122、123、125、127）。

## 工作例证（1个完整实例）

孔子祀典之订正。

- 缘起：嘉靖九年九月，帝谕订正孔子祀典，编修徐阶争之，贬为延平府推官（卷之117，嘉靖九年九月）。
- 过程：礼部会集群议上更正之奏，去王号与「文宣大成」之号，庙不称殿，易塑像为木主，笾豆十、乐舞六佾，并别祠启圣公、考正从祀（卷之117，嘉靖九年九月）。
- 结果：孔子改称「至圣先师」，祭祀规格一体降杀并颁行；至十一月冬至祀圜丘、大赦天下，改制随大礼告成而落定（卷之117、119，嘉靖九年九月、十一月）。
- 出处：卷之117（嘉靖九年九月）、卷之119（嘉靖九年十一月）。

## 关键要点（3–7条）

1. 四郊坛定名与圜丘器物之定，标志郊祀改制由议入行（卷之114、119、122）。
2. 孔子去王号、易木主是本段最具争议的改制，徐阶以争之被贬（卷之117）。
3. 庙制上撤姚广孝配享、迁德祖入祧庙、定大禘虚位，三项同向收窄「功臣／始祖」的配位空间（卷之116、121、122、124）。
4. 灾异与修省在此段高度制度化：宫中火、部院火、雷震、彗星均触发修省与人事（卷之121、124、126、127）。
5. 财政上漕运折色、通惠河成与各省积谷备荒并举，但西安六府大旱仍致「饿死的人充满道路」（卷之114、118、127）。
6. 选淑女一千二百五十八人、册九嫔，是与礼制并行的宫中人事线索（卷之119、123）。

## 与其他章的关系（2–4条）

1. 直接续接第7章的分祀定案：郊坛定名、圜丘器物与《祀仪成典》皆是第7章分祀决定的执行环节（卷之114、118、119）。
2. 下启第9章的宗庙改制：本章迁德祖入祧庙、定大禘，为第9章复四亲庙、请立专庙之议铺垫（卷之121、130、132）。
3. 孔子祀典与学礼线索接入第9章：启圣公祠定祭仪、历代帝王庙之祀、元世祖祀存废之议相继展开（卷之128、130、140、141）。
4. 边镇互援、修墙挖壕之议题延续至第9章的大同应朔之警与纳银助边墙（卷之116、118、127、131、132）。
