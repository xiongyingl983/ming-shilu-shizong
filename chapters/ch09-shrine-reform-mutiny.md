# 第9章　宗庙之议与大同兵变

覆盖范围：卷之128—卷之158（嘉靖十年七月—嘉靖十三年正月）

## 核心要义（1–3句）

这三十一卷（约两年半）是世宗由郊礼转入宗庙改制的阶段：郊礼诸坛于卷之128—132落定，重心随即移向宗庙，复四亲庙、请立专庙之议凡三提，终以地狭、门庑不备而暂止（卷之130、132、136、137）。星变、旱蝗与边警贯穿其间，彗星四次复现成为言路与阁臣更迭的引信，而大同兵变暴露了苛将、骄兵、督抚三层矛盾，是本段最重的制度性危机（卷之142、151、152、155、156、157）。

## 框架与判断规则（3–6条）

1. 当皇帝再提宗庙改制时，应预期廷议以「地形」等技术理由推延而非正面否决：复四亲庙之谕三下，终以地狭、门庑不备而止，因为宗庙动土牵涉三大殿与寝殿格局（卷之130、132、136、137）。
2. 当彗星、雷震、地震频见时，应视为言官争取宽宥议礼获罪诸臣的固定窗口：喻希礼、金等请宽议礼获罪诸臣即下锦衣卫狱，因为修省话术与议礼旧案绑定（卷之133、141）。
3. 当边镇灾歉与边警并发时，应以太仓银拨补加遣赈济郎中并行：陕西发太仓银三十万、遣叶相主赈，因为边饷与赈灾共用同一财源（卷之128、134、136）。
4. 当镇将苛役激变军情时，应预判督抚「主抚／主剿」分裂：大同兵变中潘仿主抚、刘源清与郤永请剿，因为督抚与镇将的责任归属不清（卷之155、156）。
5. 当藩府庄田与禄米积欠并发时，应预料演为治安事件：德府军校砸济南府官署、宗室积欠禄米三十余万石，因为宗禄已由财政问题转为地方治理问题（卷之134、141）。

## 关键概念（6–10条）

- 郊礼定型：孟春祈谷改于圜丘、夏至方泽大祭、朝日夕月、帝社帝稷、神祇坛，泰神殿奉昊天上帝与太祖神主（卷之128—132）。
- 《郊礼通典》：夏言进四郊礼议，帝赐名（卷之148）。
- 四亲庙／专庙之议：复四亲庙之谕与廖道南请立专庙之请，终以地形不合而止（卷之130、132、136、137）。
- 承天府：安陆州升承天府，附郭钟祥（卷之129）。
- 余盐：户部议盐法受阻四因，定淮南八钱、淮北六钱（卷之133）。
- 屯田册籍：十年一造之定例（卷之139）。
- 军功袭替法令：分生擒、斩首、当先、奇功，别地方难易、事势缓急（卷之132）。
- 御史滥举连坐法（卷之140）。
- 大同兵变：总兵李瑾挖濠堑四十里而失士心，乱兵杀瑾焚帅府（卷之155—157）。
- 皇子覃恩诏：皇第一子生后颁赦，并列宗室养赡、清理高墙庶人诸条（卷之153）。

## 心智模型（2–4条）

1. 「大礼」是隐形主线：凡触及议礼定案者几乎一律重谴（陈采、秦𤨠、杨名），而议礼功臣张孚敬却因星变被三度召还复入内阁（卷之142、143、146、149）。
2. 「星变—修省—人事」循环：卷之142至卷之152彗星四次复现，群臣借以言时政，帝屡斥其借星变胁制朝廷（卷之142、151、152、155）。
3. 「蓟镇—宣大—宁夏」三联边患结构：朵颜逼近京畿陵寝、宣大关乎边军内部积怨、宁夏直对河套吉囊（卷之146、147、157）。
4. 财政紧平衡：赈灾与军饷普遍依赖太仓银与盐引盐银，户部反复以储备难继推挡，蠲免几近逐月（卷之142、143、157）。

## 反模式（2–4条）

1. 把宗庙之议当成一次性决断：本章之议三提三止，忽视反复会误判为「已定案」（卷之130、132、136、137）。
2. 以星变论者的言辞推断其安全：杨名、郭宗皋等借星变言事者多遭拷讯、杖责与远戍（卷之143、155）。
3. 只按军事层面处置兵变：大同兵变起于苛役与欠饷，纯以剿办应对会激变军情（卷之155、156）。
4. 采信译文中的人名与干支：本段音讹、串名、干支紊乱极多，且卷之141彗星「百十五日」而没与卷之128彗星三日而没是否同一次存两说，须回底本核（卷之128、141、142、156）。

## 工作例证（1个完整实例）

大同兵变。

- 缘起：总兵李瑾在大同挖濠堑四十里，督促十分严厉急迫，失士心（卷之155，嘉靖十二年十月）。
- 过程：乱兵王福胜等焚帅府、杀李瑾，代王走宣府西城；巡抚潘仿主抚，总督刘源清与都督郤永请剿，帝命务必使国法得以大力伸张（卷之155，嘉靖十二年十月）。源清至大同以榜文提五堡旧事、捕诛多人而激变，城中释囚取械为主，郤永筑堤灌城（卷之156，嘉靖十二年十一月）。
- 结果：廷议命总兵不必遣，前总兵朱振自杀；十二月命樊继祖募镇兵、发太仆马一千五百匹（卷之156、157，嘉靖十二年十一月至十二月）。
- 出处：卷之155（嘉靖十二年十月）、卷之156（嘉靖十二年十一月）、卷之157（嘉靖十二年十二月）。

## 关键要点（3–7条）

1. 郊礼定型后重心移向宗庙，复四亲庙、请立专庙之议凡三提而止（卷之130、132、136、137）。
2. 张孚敬进退是本段晴雨表：卷之128罢归、卷之132诏召、卷之136晋华盖殿大学士、卷之141致仕，起伏皆由言官弹劾加星变触发（卷之128、132、136、141）。
3. 星变为政治语言：彗星四次复现，借以言时政者多遭重谴（卷之142、151、152、155）。
4. 财政与边事高度绑定：太仓银屡拨、开中纳粟与遣赈济郎中为机制，并裁王府庄田、革税课司、清余盐以补边储（卷之128、133、136、140）。
5. 宗室藩府由财政问题演为治安事件：德府军校砸官署、宗室积欠禄米三十余万石（卷之134、141）。
6. 大同兵变是本段最重的制度性危机，暴露苛将、骄兵、督抚三层矛盾（卷之155—157）。
7. 礼制与人事收束：废皇后张氏、册立方氏为后，张孚敬进少师、夏言晋少保，为下一阶段定调（卷之158）。

## 与其他章的关系（2–4条）

1. 上承第8章的祧庙大禘与孔子祀典：本章复四亲庙之议、启圣公祠与历代帝王庙之祀，皆是同一改制序列的延展（卷之128、130、140、141）。
2. 下启第10章（嘉靖十三年二月—嘉靖十五年十月）：宗庙规制与礼制讨论仍将以「地形」「世室」为争点延续（卷之137、158）。
3. 边事线索接入后续各章：宣大三联结构与大同兵变的善后，将影响此后边镇处置（卷之146、155、156、157）。
4. 人事线索与第7、8章的议礼集团呼应：张孚敬、夏言、方献夫、霍韬诸人进退构成连续叙事（卷之128—158）。
