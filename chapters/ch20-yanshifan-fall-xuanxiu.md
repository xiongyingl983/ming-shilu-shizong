# 第20章　倭平虏炽与世宗末政：玄修·营建·亏空

覆盖范围：卷之514—卷之557（嘉靖四十一年十月—嘉靖四十五年四月）

## 核心要义（1–3句）
这是东南倭乱收束、北虏压力却最重的一期：兴化陷城（卷515·四十一年十一月）之后，戚继光会刘显、俞大猷破平海卫，闽患遂平（卷520·四十二年四月），而墙子岭溃墙入犯致京师戒严、总督杨选问斩（卷526、卷527·四十二年十至十一月）。严世蕃终以罗龙文牵连被逮，法司论以大逆即斩于市，籍没金三万余两、银二百余万两（卷544·四十四年三月、卷551·四十四年十月）。玄修、营建、献瑞与大工加恩成稳定闭环，而户部岁入不敌岁支、超支一百一十六万两（卷552·四十四年十一月）。

## 框架与判断规则（3–6条「当…时，应…，因为…」，带卷号）
1. 当方术士假传圣旨、惊扰宫禁时，应重惩不贷，因为胡大顺伪撰万寿金书一案牵连内监赵楹即弃市（卷546·四十四年五月），帝于方术实为「纳而不笃信」。
2. 当工程告成或万寿节至时，应加恩内阁与工部，因为万寿节加恩辅臣（卷537·四十三年八月）、徐阶加特进上柱国（卷545·四十四年四月）、雷礼以工加少保（卷555·四十五年二月）皆循此例。
3. 当宗禄积弊已极时，应以条例限禄废爵而非徒事削夺，因为王府禄米总计八百五十三万石、较京师岁漕四百万石倍之（卷514·四十一年十月），遂有《宗藩条例》六十七条（卷544·四十四年三月）。
4. 当边费骤增时，应并议开纳与考满荫叙两途，因为蓟镇军饷重开捐纳（卷533·四十三年四月），同时重定边镇督抚考满条例（卷534·四十三年五月）。
5. 当城池失陷时，应依失陷城寨律论罪，因为墙子岭之败斩总督杨选、巡抚徐绅论死（卷527·四十二年十一月），遂定失陷城池罪条例（卷526·四十二年十月）。
6. 当倭乱平定后，应复水寨、团练乡兵以善后，因为谭纶《海防善后六事》即以此为要（卷526·四十二年十月、卷538·四十三年九月）。

## 关键概念（6–10条）
- 平海卫大捷：戚继光会刘显、俞大猷斩二千二百余级，闽患平（卷520·四十二年四月）。
- 兴化陷城：倭破兴化府城，同知奚世亮死之，遂调浙兵与义乌兵入援（卷515·四十一年十一月、卷517·四十二年正月）。
- 墙子岭之变：虏自墙子岭溃墙入犯，京师戒严，总督杨选斩于市（卷526·四十二年十月、卷527·四十二年十一月）。
- 失陷城池罪条例：改旧降级为依失陷城寨律斩（卷526·四十二年十月）。
- 宗藩条例：礼部集议六十七条，赐名《宗藩条例》（卷544·四十四年三月）。
- 伊王之废：废伊王朱典柍为庶人、锢高墙、削世封（卷530·四十三年二月）。
- 柘林兵变：广东柘林水兵乏粮哗变、逼省城（卷532·四十三年三月）。
- 开纳事例：边费不足条上开纳，监生、儒士、吏员纳银入监授职（卷514·四十一年十月、卷533·四十三年四月）。
- 会计亏空：岁入二百四十七万余两、岁支三百六十三万两，超支一百一十六万两（卷552·四十四年十一月）。

## 心智模型（2–4条）
1. 「玄修—营建—献瑞—加恩」闭环模型：宰辅加恩常借万寿节、工程完工、祥瑞告庙为名（卷537、卷549、卷555）。
2. 「年例银刚性膨胀」模型：山西客饷十倍于旧、蓟昌新增标兵岁增四五十万，户部与督抚反复拉锯（卷528·四十三年十二月、卷552·四十四年十一月），考满条例即为激励配套（卷534）。
3. 「募兵与客将调度」模型：倭乱之平赖义乌兵客戍与戚继光、刘显、俞大猷、谭纶互援，胜负系于粮饷不继（卷520、卷532柘林兵变）。
4. 「方士政治风险」模型：触及假传圣旨即重惩（卷546胡大顺案），而徐阶之谏为生死开关。

## 反模式（2–4条）
1. 以捐纳救边费：动辄开纳授职，吏治随之败坏（卷514、卷533、卷535）。
2. 以玄修掩亏空：采龙涎香、买黄金、访珍珠与岁计亏空并行（卷541、卷545、卷552、卷553）。
3. 以削夺代制度重建：伊王废锢、禄米削减止于个案，宗禄总额不减（卷517、卷530）。
4. 以廷杖钳制言路：凌儒荐罗洪先等被杖为民（卷517·四十二年正月）、张槚请录用吴时来等被逮（卷552·四十四年十一月）。

## 工作例证（1个完整实例：缘起—过程—结果—出处（卷号＋年月））
**闽倭之平：自兴化陷城至平海卫大捷**
缘起：四十一年十一月己酉，倭破兴化府城，毕高、翁时器缒城遁，同知奚世亮死之（卷515）；以兴化陷闻，罢巡抚游震得，起谭纶领浙兵、调戚继光义乌兵入援（卷517·四十二年正月）。
过程：四十二年四月丁卯，戚继光会刘显、俞大猷破平海卫倭，斩二千二百余级，闽患平（卷520）；李邦珍勘闽倭，叙横屿之役「命令军中每人拿一束草，填到河中再前进」，斩二千六百余级（卷522·四十二年六月）。继有仙游、王仓坪之捷（卷530·四十三年二月、卷533·四十三年四月）。
结果：惠潮海丰大破倭、擒斩千二百余（卷535·四十三年六月），残倭入粤（卷536·四十三年七月）；而柘林水兵乏粮哗变、逼省城（卷532·四十三年三月），可见胜负系于粮饷之继否。
出处：卷515·四十一年十一月、卷517·四十二年正月、卷520·四十二年四月、卷522·四十二年六月、卷535·四十三年六月。

## 关键要点（3–7条）
1. 严世蕃以罗龙文牵连连坐，法司论大逆即斩，籍没银二百余万两（卷540、卷544、卷551）。
2. 倭乱之平赖募兵客将与将领互援，而粮饷不继即生兵变（卷520、卷532）。
3. 宗藩为嘉靖末第一财政黑洞，禄米八百五十三万石（卷514）。
4. 边镇年例银刚性膨胀，蓟昌新增标兵岁增四五十万（卷528、卷552）。
5. 玄修—祥瑞—大工加恩成闭环，言官以谏被杖被逮（卷517、卷552）。
6. 《宗藩条例》为应对宗禄危机之制度回应（卷544）。
