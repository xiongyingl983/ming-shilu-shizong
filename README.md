## 数据来源与可靠性（重要）

- **底本**：官修《明世宗肃皇帝实录》，公共领域。
- **白话译文与整理**：来自**识典古籍**（`https://www.shidianguji.com/book/LS0026`），经抓取并按原文句序装配；
  本仓库的派生文件**仅供个人研读**。
- 该站白话层是**机器翻译**，实测有三类系统性缺陷（详见 `references/data-provenance.md` §4）：
  1. 把原文「上从之」译成**先秦诸侯名**（齐景公/晋悼公/魏文侯…）—— 75 处、68 卷；
  2. **自造年号**（原文「四十二年」被写成「万历四十二年」）—— 「万历」28 处、26 卷，
     个别处**还增补原文所无的事实**；
  3. **人名译形游移**（曾铣→杨铣/萧铣/仇铣/林铣，仇鸾→萧鸾/吕鸾/江鸾 …）。
- **原文层经抽查是干净的** → **一切引用以 `scripts/raw_juan.py` 对照的原文为准，译文只作导览**。
